Swipe Photo

Pilih foto-foto bagus dengan cepat.

  1. Pilih folder yang berisi foto.
  2. Untuk tiap foto, tekan → kalau bagus, atau ← untuk lewati. Bisa juga digeser (swipe).
  3. Foto bagus otomatis dipindah ke folder Bagus di dalam folder itu. Foto lain tetap di tempatnya.

Proyek kamu

Pilih folder foto

Klik nama folder untuk membukanya. Kalau sudah di folder yang berisi foto, klik Pakai folder ini.

📂 Jendela pilih folder sudah terbuka

Pilih folder fotomu, lalu klik tombol Choose.

Jendelanya tidak kelihatan? Mungkin tertutup browser. Tekan ⌘ + Tab untuk mencarinya.

Klik foto (atau tekan 1–9) untuk menandai 👍. Yang tidak ditandai akan dilewati.

Salah pilih? Tekan ↑, atau klik foto di daftar untuk memilih ulang.

Cara memilih
→
Bagus — dipindah ke
← ↓
Lewati — foto tetap di tempatnya
↑
Batalkan pilihan terakhir
👆
Geser foto ke kanan = bagus, ke kiri = lewati (sentuh, mouse, atau dua jari di trackpad)
Spasi
Perbesar foto 100% untuk cek ketajaman (atau klik foto). Scroll untuk zoom lebih jauh.
B
Bandingkan foto-foto beruntun (seri) berdampingan
🖱️
Klik foto di daftar untuk melihat & memilih ulang
Esc
Kembali ke daftar proyek. Semua pilihan tersimpan.
